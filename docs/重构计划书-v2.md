## 0. 结论先行

**能改，而且底子合适，但这是一次换骨，不是调参。**

现有代码里有两层写死的耦合必须拆掉：

| 现状 | 问题 | v2 需要变成 |
|---|---|---|
| `weapons[]` = 6 个元素 × 各自一种固定弹道 | 元素与「怎么打出去」绑死，无法表达「同系有弹道/生成/全屏三种技能」 | `skills[]` = 21 个技能，`el`（系）与 `mode/area`（怎么打）正交 |

可以整块保留的：状态机（menu/levelselect/playing/levelup/over/cleared）、波次与分批刷怪（你上周那版）、Canvas 渲染管线、`tools/` 三个模拟工具、`platform.js` 的微信分支。

## 2. 数据模型

### 2.1 七系（`elements`）

物理 / 电 / 火 / 风 / 冰 / 水 / 毒 —— 每系一个主色 + 图标，只用于分类与取色。

### 2.2 21 个技能（`skills[]`）

字段：`{ id, el, name, mode, area, cd, ratio, tags[], cond?, bounce?, initial? }`

- `mode`：`bolt` 弹道 / `generate` 生成 / `fullscreen` 全屏
- `area`：`single` 单一目标 / `line` 路径单位 / `area` 范围单位 / `all` 全屏
- `ratio`：伤害倍率，**统一乘以 `power.base = 3`**，这样 0.5 倍率的传导系和 1.5 倍率的黑洞能直接比较
- `cond`：全屏技能的携带前置（`{ elec: 4 }` 或 `{ fire: 2, wind: 2 }`）

### 2.3 派系强化卡（`factionStats`，15 种）

13 种按 tag 的属性卡 + 2 种通用卡（技能伤害 / 属性伤害）。每张卡绑定**一个系 + 一种属性**，只在「你携带了该系、且该系有技能带这个 tag」时才进卡池。

### 2.4 携带与局内（`loadout`）

```
loadout.slots = 8        // 局内技能格
loadout.maxCarry = 7     // 局外自选上限（第 1 格固定白银子弹）
```
- 全屏技能**不进局外选择**，条件满足后作为三选一中的一个选项出现，**占 1 格**；
- 想要终结技 → 固定拿 4 个前置 + 1 格终结技 = 用掉 5 格，只剩 3 格自由搭配（这是本方案的核心取舍）。

## 3. 结算公式（必须唯一，不能各写各的）

```
单次伤害 = power.base(3) × ratio
         × Π(1 + 技能伤害卡) × Π(1 + 属性伤害卡)
         × (1 + 星辉总加成 + 局外攻击力)
         × (1 − 破防) / 敌方防御
冷却     = cd × Π(1 − 冷却卡) × (1 − 局外攻速)
持续时间 = base × Π(1 + 持续卡)
范围     = base × Π(1 + 范围卡)
```
样例（便于回归断言）：白银子弹 1 级、无任何加成 → 单发 3 点；打 2.2 血史莱姆一炮一个，打 9 血重装 3 发。

## 4. 六种攻击方式的实现

| 模式 | 判定 | 渲染 | 工作量 | 复用 |
|---|---|---|---|---|
| 单一目标 | 现有锁定 + 追踪弹 | 现有 | 低 | 100% |
| 路径单位 | 线段与敌人圆做「点到线段距离」判定，可穿透 | 一条发光折线（带渐隐） | 中 | 线段工具新写 |
| 范围单位 | 圆形区域，一次性或持续 tick | 圆 + 环 | 中 | 毒雾区逻辑复用 |
| 弹道 | 直线飞行，不因目标死亡改变方向（与现有追踪弹不同） | 直线拖尾 | 低 | 现有弹体改造 |
| 生成 | 找「敌人最密集点」→ 在该点落地 | 落地阴影 + 爆点 | 中 | 需要新的聚类找点 |
| 全屏 | 一次性遍历全部在场敌人（`enterY` 之后） | 自下而上的横扫色带 | 低 | — |

新增两个小工具函数：`distToSegment(p, a, b)`、`densestPoint(radius)`（网格采样，最多 12×16 候选，避免 O(n²)）。

## 7. 局内卡池

```
候选池 = {
  强化卡： 对每个已携带技能 s：
             对 s.el 的每个 tag t（且 s 拥有 t）：出一张「系·t」卡（未达上限）
 通用卡： 对每个已携带技能：出「技能伤害」卡（无上限）
          对每个有技能的系：出「属性伤害」卡（无上限）
 全屏卡： 若某全屏技能 cond 满足、尚未拥有、且还有空格：出「获得 XX」
}
每级三选一从池中随机 3 张；保留 3/6/9 波的刷新机会（你已有的机制）
```
保证：**局内不会再出现未携带的非全屏技能**（按你选的方案）。

## 11. 需要你拍板的 6 个点（括号里是我的默认值，回「按你写的」就行）

1. **冷却列 `(1,5)` / `(5,10)` 的含义** —— 我理解为「基础值～可压缩到的下限」，取基础 1.0s / 7.5s。若其实是「数量区间」请纠正。
2. **羁绊计数口径** —— 我按「同系派系卡张数」（默认）。
3. **全屏技能占格** —— 占 8 格之一（按你上一条回答）。
4. **不可知域（毒·全屏，cd 0）** —— 实现为常驻，每秒结算一次全场毒伤。
5. **携带是否允许同一技能带两份** —— 我按「不可重复」。若允许，羁绊可以靠重复堆，平衡会完全不同。
6. **「属性伤害卡」的生效范围** —— 我按「该系所有技能的伤害」；若你指的是「该系所有伤害来源（含 DoT/灼烧）」，实现上要再分一层。
