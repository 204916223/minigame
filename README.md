# 像素割草 · 关卡制小游戏

原生 JavaScript + Canvas 2D，同一套核心运行于浏览器与微信小游戏。当前为 v2 规则重构版，以 `docs/design/` 原图和用户确认规则为准，实施说明见 [重构计划书-v2.md](docs/重构计划书-v2.md)。

## 玩法

首页可左右切换三款像素角色并保存选择，战斗中同步显示；当前共用养成属性。属性区显示实际攻击、防御、生命、护盾和局外加成，点击备战技能区打开配置弹窗，底部“开始对战”进入选关。

- 普通关卡要求从 14 个普通技能中选满 7 个候选。无尽解锁后即使不足七个，也可进入选关翻页，但不能开始普通关；无尽开战不检查备战数量。白银子弹固定携带。
- 开局只装备白银子弹。升级四选一，每次至少一个强化；第 3、6、9……次在有合资格候选时保底一个新技能选项。
- 普通新技能的同一元素不能连续三轮出现在选项中，全屏技能不受此限制。刷新不推进轮次，同轮刷新出现过的元素合并记录；元素限制、满槽或前置不满足时不给违规技能。
- 局内最多装备 6 个技能，含普攻及全屏技能。获得技能不附送强化。
- 全屏技能不进入局外候选。满足实际装备前置且有空格后，首次选卡有 30% 概率出现；每次完成选卡（获取技能或强化）增加 10 个百分点，第 8 次必出，未选则后续保持必出。所有全屏技能共用概率，每轮最多出现一个；选中全屏后，其余合资格全屏从 30% 重新累计。刷新重新抽取但不增加概率，每三次新技能保底也不绕过全屏概率。
- 不可知域要求两个毒技能且没有风技能；获取后禁止装备风系。局外候选中可以有风系。
- 技能强化卡按“技能名·派系”区分；技能伤害每级 +20%，只影响指定技能。属性伤害改为每种元素一张卡、每级 +10%，影响该元素所有已获得及后续获得的技能（含全屏），例如电系覆盖闪电链接、落雷和雷暴。只有拥有对应元素的技能才会出现该属性卡；两类伤害卡均可无限升级、无伤害代价。
- 装备三个技能（含普攻）后解锁羁绊。羁绊统计已装备技能的机制标签；2/4 件取最高档，4 件替换 2 件，只增强有相应标签的技能。
- 多重增加初始不同目标。分裂首张卡开启两个半攻击力子弹，后续每级增加一个目标，最多分裂一代。
- 卡增益及伤害代价加算；到卡上限不再出现该卡，羁绊额外相加。右侧当前强化中，达到卡上限或实际效果硬上限的项目显示红字，包括叠加羁绊和局外加成后已达最短间隔的冷却。若尚未到卡等级上限但效果已经封顶，出现的卡也标红并提示“本次无增益”，仍明确提示原有伤害代价。
- 先计算有效防御：`防御 × (1 - 破防)`；攻击高于有效防御时做减法，否则（包括相等）造成 `25 + 角色等级 + 波次` 的基础伤害，再乘技能结算倍率（闪电链接 0.5，其余 1）和同属性半伤系数。持续伤害按每秒结算后乘时间。
- 所有加成后的冷却硬下限：生成 8 秒，普通弹道 3–4 秒，白银子弹 1 秒，闪电链接 2 秒，折射激光 10 秒。基础冷却高于下限，详见规则文档。闪电链接扣防后伤害减半；折射激光倍率调为 2.5。
- 冰冻基础概率 10%，只受冰冻卡和羁绊提升；冻结时长随敌人抗性缩短。
- 怪物随机获得七种元素之一，颜色按原图：物理灰、电黄、火红橙、风青绿、冰蓝、水浅蓝、毒紫；受到同属性攻击时伤害减半。
- 生成技能按怪物移动、冻结和减速预估 1 秒后的落点，避开预计会被已有预警或已发出弹道先击杀的残血目标。先显示圆圈，等待 0.5 秒，再用 0.5 秒由外向内填满；填满才爆发伤害、控制及持续区域。预警开始后落点固定，目标死亡不取消爆发，走出范围可以躲避；范围强化仍扩大命中区域。
- 五种非持续全屏技能用对应元素色横线从画面底部向顶部扫描，历时 0.8 秒；敌人被扫描线碰到时才结算伤害和控制，每次扫描对同一目标仅命中一次。采用相对运动的交叉检测，兼容移动敌人和低帧率，伤害保留施放时快照；暂停及选卡冻结扫描，2× 同步加速。不可知域改为常驻毒紫色背景，沿用单层中毒，不反复播放扫描或爆炸。全屏获取前置与概率不变。
- 弹道飞行速度为 1600 像素/秒，保持直线和线段碰撞，施放冷却不变。
- 左侧竖排羁绊：图标及名称缩小 50%，行距同步缩短，避开底部装备区。圆环四段各代表一个派系技能，最多亮四段；三技能解锁前仅显示进度。右侧显示当前选中技能的强化，点击底部技能格切换，拿卡后自动定位对应技能。

## 关卡与进度

5 关，每关 10 波，刷怪总数为 **30、30、51、100、100、302、500、500、503、1005**。第 3/6/9/10 波各含 1/2/3/4 个小首领；末波还含一个最终首领，最后出场。每波刷完后 3 秒接下一波，残怪保留；最终波清场结算。敌人进场后才能被伤害。

角色初始攻击 200、防御 100、生命 400；第一关首只普通怪实际防御 50、生命 150，随后按怪型、关卡、波次和逐只成长。敌人攻击力等于碰撞时剩余生命，角色用绝对防御抵扣（未破防也采用上述保底），再扣护盾和生命。

普通关移速按怪物出生波次固定：第 1～6 波无额外加速，第 7～10 波分别 +10%、+20%、+30%、+40%，与角色等级无关。最终移速为怪型基础移速 × 关卡速度系数 × 波次倍率；残敌保持出生时的移速。角色升级仍在第 1～3 波增加敌人血量、第 4～6 波增加敌人防御，第 7 波起不再触发敌人成长。刷怪批次和频率沿用现有规则，无尽速度继续每波增加初始的 5%、最多增加 50%。

战斗右上角可切换 `1× / 2×` 倍速。第一关至少一星通关后免费解锁，也可点击锁定按钮并确认花 2000 金币提前永久解锁，优先扣局外金币、不足部分使用本局金币。确认窗口暂停战斗，取消和金币不足都不扣款。解锁随 v3 存档保存，普通关和无尽共用，每局默认 1×。2× 以原步长多推进一次战斗，使移动、攻击、刷怪、冷却、状态及战斗计时同步加速；单次击杀的金币、经验及伤害不变。暂停、选卡、失败和通关会停止推进。可在 `tools/speed-preview.html` 用隔离存档验证按钮、购买和免费解锁。

敌人突破防线扣血；剩余生命严格大于 30% / 60% / 90% 分别获得 1 / 2 / 3 星，满血附加边框。至少一星解锁下一关。第 3 / 6 / 9 波之后各获得一次选卡刷新。

每击杀一只怪获得 1 金币，首领也相同。局外五项强化各最多 40 次：攻击每次 +2.5% 初始值，防御和生命每次 +5% 初始值，冷却每次 -0.5%，护盾每次 +50。每项独立计价：`1000 + 该项已购次数 × 500`。本次发布清除旧版进度，后续新增进度按下文存档规则保存。

局外强化页提供“重置强化”：确认后将五项强化全部恢复至 0 级，按当前已购各级费用之和返还 80% 金币；每项已投入为 `1000 × 等级 + 500 × 等级 × (等级 - 1) / 2`。例如攻击升 3 次花费 4500，重置退 3600；重购从每项 1000 金币开始。确认窗口显示投入和退款，取消不修改数据，无强化时禁用按钮，重复确认不重复退款。星级、无尽纪录、备战和倍速解锁保留；结果立即保存至原 v3 存档。

## 无尽模式

选关共两页，默认第一页显示常规关卡，第二页显示无尽模式及历史纪录。左右箭头和键盘方向键切换，带横向翻页动画与 `1 / 2`、`2 / 2` 页码。未解锁也可翻到无尽页查看，前三关全部至少一星通关后才能开始。每波 **1000 个普通怪 + 3 个小首领 + 2 个大首领**，总计 1005 个，波数没有上限。沿用刷完后 3 秒接下一波、保留残敌的机制，每过三波获得一次刷新。

当前试玩成长：第 n 波血量为初始 × `1 + 15% × (n-1)`，防御为初始 × `1 + 10% × (n-1)`，速度为初始 × `min(1.5, 1 + 5% × (n-1))`。初始怪物数值与第一关相同；无尽不叠加普通关的波内及角色升级成长，速度不会超过初始的 150%。出怪间隔从 1.5 秒随波次缩短，最低 0.5 秒，批次数量仍随角色等级变化。

普通关击杀经验统一为怪物原始经验的 75%。无尽每击杀一个敌人得 0.5 金币，经验在普通关基础上再减半，即原始经验的 37.5%（75% × 50%），均保留小数；所有普通怪及首领一致。无需选满备战技能，局内可以从所有普通技能中获取，装备数量不限；**全屏前置及不可知域与风系互斥保留**。技能栏翻页仅影响展示，所有已获得技能同时生效。特殊强化按原上限移出卡池，技能伤害和属性伤害卡无限升级；所有可获得技能及特殊强化收集完后，只出现这两类伤害卡。

局外强化和已有星辉加成继续生效；无尽不产生通关星级。失败、返回无尽页面和重试都会正常结算本局金币，重试从第一波开始。无尽页显示“最高通过波次”和“单局最多击杀”：进入下一波时才算通过上一波，当前挑战波次不计入；击杀不跨局累加，两项纪录分别取历史最大值。过波时保存，失败、主动退出及重试前也会保存；普通关不修改无尽纪录。纪录只保存在当前设备，新增字段缺省为零，沿用 v3 存档，不再次清档。可用 `tools/endless-preview.html` 检查解锁、空备战和多页技能栏，不改实际存档。

## 本次发布与清档

v24 发布改用 `pixelMowProgress.v3` 存档；玩家首次加载新版时，金币、局外强化、星级、满血标记、关卡解锁和备战选择全部重置为新玩家默认状态。仅清理本游戏的旧键 `pixelMowProgress` 和 `pixelMowProgress.beforeV2`，不清除同域其他数据。浏览器和微信存储均执行相同规则。旧页面仍运行时写入的是旧键，不能覆盖新版进度。

后续发布必须保持新存档键不变，才能保留本次清档后的新进度。未重新加载的旧页面仍暂时使用旧版本；清档在加载新版时生效，没有服务器端远程即时清档。

`npm run release` 先运行全部检查，再生成仅含 `index.html`、`game.js` 和八个 `src/*.js` 的 `dist/`；`dist.sha256` 是发布后的文件核对清单，不随网页上传。每次上线递增 `index.html` 中的资源版本号（当前为 `v=31`）。

GitHub Pages 使用 `.github/workflows/pages.yml`：推送到 `main` 后自动执行测试、打包并发布 `dist/`。首次需在仓库 Settings → Pages 中将 Source 设为 GitHub Actions。默认访问地址为 `https://204916223.github.io/minigame/`，无需自有域名。原 QW Pages 与 GitHub Pages 域名不同，浏览器不会跨站点继承存档；不同站点的进度各自保存。

## 开发与验证

```bash
npm run verify
npm run serve
```

浏览器访问 `http://127.0.0.1:8080/`。微信开发者工具可导入当前目录，发布前需替换 `project.config.json` 中的 `touristappid`。

全屏扫描、毒域背景、强化满额标红与属性共享可在 `http://127.0.0.1:8080/tools/fullscreen-preview.html` 检查；使用独立测试存档，不影响真实进度。

生成特效可在 `http://127.0.0.1:8080/tools/combat-preview.html` 分阶段检查或播放，使用正式战斗与渲染代码；预览不写入游戏进度。

```bash
node tools/mechanics-check.js
node tools/offscreen-check.js
node tools/generated-check.js 5
node tools/sim.js --policy all --seeds 10 --levels 0
node tools/grind-sim.js --policy random --seeds 10 --attempts 8 --levels 0
node tools/meta-sim.js
```

模拟器支持 `random` 和 `bond`。通关口径为至少一星；`sim` 每个样本使用新档，`grind-sim` 失败后购买养成再试。模拟时间不含玩家思考选卡的耗时，结果不能替代实玩和微信真机性能检查。

## 代码结构

- `src/config.js`：技能、派系、元素、敌人、关卡及可调初值。
- `src/rules.js`：技能前置、卡池资格、羁绊、派生属性、减法伤害和存档清洗。
- `src/combat.js`：直线弹、线段/反射、传导、生成区域、全屏、分裂和持续伤害。
- `src/gameplay.js`：对局状态、选卡、波次、经验、金币与养成。
- `src/renderer.js` / `src/input.js`：候选选择、四选一、六格技能栏、渲染与输入。
- `src/platform.js` / `src/audio.js`：浏览器/微信适配与合成音效。
- `tests/`：规则、战斗、波次、旧档和输入/渲染回归；模拟器共用隔离运行环境。

图中空白冷却及未给出的基础攻击、防御、半径、控制和持续伤害参数均为试玩初值，集中于配置/规则代码，尚未完成正式平衡验收。
