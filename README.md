# 像素割草 · 关卡制微信小游戏

同一套 Canvas 2D 核心同时运行于微信小游戏和浏览器。游戏采用配置驱动的关卡制：默认 5 关，每关 3 波，每波严格生成配置数量的敌人，不补刷、不提前清场；该批敌人全部处理完后进入 3 秒转场。

## 规则

- 敌人突破防线会扣血；我方血量归零立即失败。
- 第三波完成后按剩余生命比例结算：`>30%` 一星、`>60%` 二星、`>90%` 三星。
- 100% 满血通关会在三星外增加边框。
- 至少获得一星才会解锁下一关；进度保存在微信本地存储或浏览器 `localStorage`。
- 连升多级会依次完成对应次数的三选一，不会吞掉升级奖励。

## 结构

- `src/config.js`：角色、敌人、技能及关卡/波次配置。
- `src/platform.js`：Canvas、坐标、微信 `safeArea` 和本地存储适配。
- `src/audio.js`：音频上下文解锁与合成音效。
- `src/gameplay.js`：战斗、波次、升级队列、星级和解锁规则。
- `src/renderer.js`：战场、HUD、关卡选择和结算界面。
- `src/input.js`：微信触控与浏览器输入。
- `game.js`：加载模块并启动主循环。

## 调整关卡

编辑 `src/config.js` 中的 `levels`。每关必须配置三个 `waves`，其中 `kills` 是本波固定生成的敌人总数，`interval` 是刷怪间隔，`pool` 是敌人权重，`boss: true` 表示最后一只固定生成为首领。

## 验证和试玩

```bash
npm run verify
npm run serve
```

浏览器访问 `http://127.0.0.1:8080/`。微信开发者工具可直接导入此目录；正式发布前需替换 `project.config.json` 中的 `touristappid`。
